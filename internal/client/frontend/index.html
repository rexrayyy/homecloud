Установить или запустить HomeCloud

Ubuntu · Intel/AMD x86_64 · без sudo. Используются хост, данные SSH и проверенный ключ выше.

У каждого порта свои файлы и настройки. Сервис слушает localhost сервера. После перезагрузки запустите снова. Установка не подключает автоматически.

Подключить диск Windows

Windows WebClient не поддерживает Bearer-аутентификацию сервера. Учётные данные и прокси без аутентификации не создаются. Передача файлов выше остаётся доступной.
